# 配置说明

## SDK 与环境边界

SDK 本身应保持可移植性，不应隐式读取 `.env`、不应根据当前目录做推断。  
这类配置应放在调用层（`use_cases/` 或应用入口）：

- 日志级别
- 提供商凭据
- 文件路径与运行时目录
- 默认行为开关

## 推荐约定

1. 每个运行入口提供单独 README，列出运行方式与必要环境变量。
2. 通过参数传参替代全局单例。
3. 文档内以“假设已在入口处处理环境”为前提描述行为。

## 文档与版本

文档与 API 版本应同步变更，发布前确认：

- 示例代码可运行
- 示例文本与当前参数名一致
- 破坏性修改同步更新迁移说明
