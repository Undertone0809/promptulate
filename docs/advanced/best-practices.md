# 最佳实践

## 文档维护

- 入口页面保持简洁，详细内容下沉到子页。
- 将 `use_cases/*/README.md` 与主文档保持链接映射，防止说明偏离。
- 变更前先本地跑 `npm run docs:dev` 再提交。

## 变更策略

1. 功能文档与示例代码在同一次 PR 中更新。
2. 兼容性变更必须注明升级路径。
3. 目录名与锚点变化先同步更新侧边栏配置。

## Vercel 部署建议

- 建议开启 PR 预览，文档变更自动生成预览链接。
- 生产部署使用主分支保护，避免未通过审阅的内容直接上线。
- 可考虑在 `docs/index.md` 放置“最近更新”区块，帮助用户快速定位变更。
